💡 Astuce — comparer plusieurs altitudes de la même ville : ajoute-la, saisis une altitude puis clique Valider ; le panneau reste ouvert, saisis une autre altitude et clique à nouveau Valider — répète autant de fois que voulu, puis ferme le panneau avec le ×.
💡 Accès direct par API (ex : raccourci, appli mobile) — passe des coordonnées GPS dans l'URL au lieu de chercher une ville :
?lat=45.9237&lon=6.8694&alt=1035&nom=Chamonix (alt et nom sont optionnels)
Plusieurs points d'un coup, séparés par ;, chacun au format lat,lon,alt,nom :
?points=45.9237,6.8694,1035,Chamonix;48.8566,2.3522,,Paris
💡 Accès par API avec un NOM de ville — le site fait lui-même le géocodage, aucune coordonnée à fournir :
?ville=Narbonne · ?ville=Chamonix&alt=1035
Plusieurs villes d'un coup, séparées par ;, chacune au format Nom ou Nom,alt (avec ville= ou villes=, les deux marchent) :
?ville=Narbonne;Chamonix,1035;Lyon
